# 需求文档

## 1. 应用概述

### 1.1 应用名称
纹藏（非遗染织刺绣数字平台）

### 1.2 应用描述
「纹藏」是一款聚焦蜡染、扎染、苗绣等非物质文化遗产染织刺绣领域的数字平台。平台提供经典非遗纹样数字化档案展示、AI纹样辅助生成、非遗守艺人展示连接、线下非遗技艺体验预约以及文创作品在线订购等功能，致力于非遗文化的数字化记录、传承与创新推广。

## 2. 用户与使用场景

### 2.1 目标用户
- 非遗文化爱好者、传统手工艺研究者及设计师
- 寻求非遗技艺线下体验与学习的普通大众
- 喜爱非遗文创产品的消费者

### 2.2 核心使用场景
- 浏览检索经典蜡染、扎染、苗绣等纹样档案及工艺背景
- 输入创意主题词由AI生成全新非遗风格纹样及寓意解读
- 了解非遗守艺人背景并预约线下技艺体验项目
- 选购非遗文创作品并在线提交订单

### 3.2 功能说明

#### 3.2.1 首页
- 平台理念介绍：展示「纹藏」数字化传承与创新的核心理念与定位。
- 精选纹样轮播：展示平台推荐的经典非遗纹样图集。
- 功能入口导航：提供快速跳转至纹样图库、AI工坊、守艺人展厅、体验预约、文创商城的导航入口。

#### 3.2.2 纹样图库
- 纹样列表页：
  - 展示数字化纹样卡片列表，包含纹样名称、类别、所属地区、缩略图等基本信息。
  - 支持按类别（蜡染、扎染、苗绣）进行分类筛选。
  - 支持按关键词进行名称与工艺搜索。
- 纹样详情页：
  - 展示纹样高清图片、名称、收录时间、类别、所属地区、工艺技法详情及纹样文化寓意说明。

#### 3.2.3 AI纹样工坊
- 纹样创作：用户输入主题词（如「蝴蝶妈妈 苗绣」）并选择纹样类别（蜡染/扎染/苗绣）。
- 智能生成：系统根据输入生成全新纹样图案，并自动输出纹样命名与寓意解读文案。
- 成果保存：支持用户将生成的纹样图案及文案保存至个人中心的「我的纹样」。

#### 3.2.4 守艺人展厅
- 守艺人列表页：展示非遗守艺人基本卡片，包含姓名、非遗称号、擅长工艺类别。
- 守艺人详情页：展示守艺人个人简介、传承称号、代表作品展示及关联体验项目。

#### 3.2.5 体验预约
- 预约表单填写：用户选择指定守艺人/工坊、体验项目、预约日期及具体时段，填写联系人姓名与联系电话。
- 预约提交：提交后数据写入后端存储，生成预约记录。

#### 3.2.6 文创商城
- 商品列表页：展示文创商品卡片，包含商品名称、价格、对应工艺及出自守艺人。
- 商品详情页：展示商品图片、名称、价格、详细工艺说明、创作者守艺人信息。
- 下单购买：支持用户选定商品后提交购买订单，生成订单数据写入后端存储。

#### 3.2.7 用户系统
- 注册与登录：支持账号注册与登录认证。
- 个人中心：
  - 我的纹样：展示用户在AI工坊中保存的生成纹样记录及文案。
  - 我的预约：展示预约记录列表，包含项目、日期时段、工坊信息及状态（待确认/已确认/已完成）。
  - 我的订单：展示文创商城提交的订单记录及状态。

## 4. 业务规则与核心逻辑

1. 权限控制：纹样浏览、守艺人查看、文创浏览无需登录；AI纹样保存、提交体验预约、商城下单购买、个人中心查看必须为登录状态。
2. AI生成记录存储：用户点击「保存到我的纹样」后，该生成记录与当前用户账号关联并持久化存储。
3. 预约状态流转：用户提交预约后初始状态为「待确认」，经处理后流转为「已确认」，履约结束后变更为「已完成」。
4. 订单创建逻辑：用户在文创商城提交下单请求后，系统记录所购商品、价格、收件信息并生成独立订单编号。
5. 检索与筛选逻辑：纹样图库支持类别单一选择与多关键词组合匹配查询。

## 5. 异常与边界情况

| 场景 | 触发条件 | 表现行为 |
| :--- | :--- | :--- |
| 预约表单不完整 | 未填写联系人、电话或未选择时段 | 提示对应必填项缺失，阻止提交 |
| 手机号格式错误 | 预约时填写的联系电话格式不规范 | 提示联系电话格式有误 |
| AI生成超时或失败 | 生成服务响应异常 | 提示生成失败并允许用户重新发起生成 |
| 未登录操作拦截 | 未登录用户尝试保存纹样、预约或下单 | 引导跳转至登录页面，登录后返回操作流程 |
| 搜索无结果 | 检索关键词无匹配纹样数据 | 页面展示空状态提示，并提供清空筛选选项 |

## 6. 验收标准

1. 用户可正常访问首页，浏览精选纹样轮播并跳转至各业务页面。
2. 在纹样图库中，可按蜡染/扎染/苗绣类别进行筛选，或输入关键词进行精准搜索并查看纹样完整详情。
3. 在AI纹样工坊输入主题词并选择类别后，可获得生成的纹样图片、名称及解读，且可成功保存至「我的纹样」。
4. 在守艺人展厅可浏览守艺人列表及其详细生平、作品展示。
5. 用户可选择守艺人与体验项目，填写有效联系信息完成预约，并在「我的预约」中查看状态。
6. 用户可在文创商城选择商品完成下单流程，并在「我的订单」中查看到对应订单信息。
7. 用户可完成注册与登录，并在个人中心完整查阅个人保存的纹样、预约与订单列表。
